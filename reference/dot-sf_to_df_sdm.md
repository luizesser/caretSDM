# Transform a occurrences simplefeature in a data.frame.

Transform a occurrences simplefeature in a data.frame.

## Usage

``` r
.sf_to_df_sdm(occ_sf)
```

## Arguments

- occ_sf:

  SimpleFeatures to transform in data.frame. Usually from occurrences
  slot.

## Value

Data.frame with three columns: "species", "decimalLongitude" and
"decimalLatitude".
